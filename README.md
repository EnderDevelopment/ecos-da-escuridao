# Minecraft Bedrock Horror Add-on

Ecos da Escuridão is a Minecraft Bedrock horror add-on built around escalating dread, ambient horror sounds, darkness effects, movement slowdowns, and a stalking Enderman encounter. Fear increases in dark and underground areas, and can rise faster when you stay still.

## Install

1. Keep the `behavior_pack` and `resource_pack` folders together.
2. Import both packs into Minecraft as `.mcpack` archives, or copy them into the matching `behavior_packs` and `resource_packs` folders in your Minecraft Bedrock data directory.
3. Create or edit a world and enable both The Hollow behavior pack and resource pack in the world’s pack settings.
4. Enable cheats and any scripting API or creator experiments required by your Bedrock version.
5. Use Minecraft Bedrock Edition 1.21.0 or later with the stable `@minecraft/server` 2.0.0 module.

## Use

1. Enter the world. A message introduces the add-on and its start command.
2. Type `!hollow` in chat to start or intensify the hunt for yourself.
3. Explore dark areas and underground to build dread and trigger horror events.
4. Type `!hollow reset` to clear your dread state.
